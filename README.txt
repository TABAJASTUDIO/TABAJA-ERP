TABAJA ERP V2.4 — VOUCHER ENGINE ALPHA 1

This build is based on V2.4 and introduces the first real keyboard-first Voucher Core:
- Cell/Grid navigation instead of normal form inputs
- Enter / Tab moves to next cell
- Up / Down moves between voucher cells
- Inline Ledger List appears in the right panel while typing
- Up / Down + Enter selects a ledger
- Escape closes the inline list and returns to the same cell
- Dynamic right-side Current Field help
- Existing companies and ledgers remain stored under the same localStorage keys

TEST:
1. Open a company.
2. Press V for Vouchers.
3. Move with Enter and arrow keys.
4. At Party A/c name, type the first letters of a ledger.
5. Use Up/Down and Enter to select.
